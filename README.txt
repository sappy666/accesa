IMPORTANTE PARA REDES SOCIALES
El HTML ya contiene Open Graph y Twitter Card.
Al publicar el sitio, conviene reemplazar `content="assets/og-accesa.png"` de og:image y twitter:image por la URL absoluta pública, por ejemplo:
https://tudominio.cl/assets/og-accesa.png

Esto permite que WhatsApp, LinkedIn, Facebook, X y otros crawlers encuentren la imagen con mayor fiabilidad.
